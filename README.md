# AI Customer Support & Ticket Automation Platform

An AI-assisted customer support platform designed to help
support teams classify, prioritize, investigate and respond
to customer tickets.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Python
- FastAPI

### Database
- PostgreSQL

### AI
- LLM
- RAG
- Vector Search
- AI Agents

### Infrastructure
- Docker
- Redis
- GitHub Actions
